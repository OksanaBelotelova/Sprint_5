Проект для 5 спринта
Тесты находятся в папке tests и содержать 4 блока:
**test_user_registration.py** - тесты на функциональность «Регистрация пользователя»
**test_user_login.py** - тесты на функциональность «Login пользователя»
**test_user_logout.py** - тесты на функциональность «Logout пользователя»
**test_create_advertisement.py** - тесты на функциональность «Создание объявления»

В файле **locators** - находятся локаторы на используемые элементы
В файле **conftest.py** - находится фиксутра которая запускает и закрывает url для каждого теста
В файле **data.py** - лежат данные существующего юзера
В файле **helpers.py** - находится функция по созданию рандомного имейла
